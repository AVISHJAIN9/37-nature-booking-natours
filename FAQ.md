# Frequently Asked Questions: Wanderly (Natours) SASS Tour UI

### 1. What is Wanderly (Natours) SASS Tour UI?
Outdoor adventure tour booking landing showcase built with modern responsive 7-1 SASS architecture.

### 2. What technology stack does it use?
Built with SCSS (7-1 Architecture), CSS Grid / Flexbox, Vanilla JS.

### 3. Where is this project deployed?
Hosted live at: https://avishjain9.github.io/37-nature-booking-natours/

### 4. How can I run it locally?
Follow the installation and setup guide provided in [docs/SETUP.md](docs/SETUP.md) or the repository `README.md`.
